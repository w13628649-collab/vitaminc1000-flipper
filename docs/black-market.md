# 黑市倒卖:调研与设计

2026-10-19。起因:实测精炼 90% 亏本,只有开专注才有利润,专注每天有限,
天花板是每天几十万银币。转向黑市——在主城秒买装备,运到 Caerleon 卖给黑市。

## 开源工具都怎么做的

GitHub 上真正相关的就三个,核心算法完全一样:

| 仓库 | ★ | 语言 | 最后更新 |
|---|---|---|---|
| [mattias-wiberg/AlbionFlipper](https://github.com/mattias-wiberg/AlbionFlipper) | 36 | JS | 2025-09 |
| [felipelincoln/albion-blackmarket-arbitrage](https://github.com/felipelincoln/albion-blackmarket-arbitrage) | 39 | Python | 2022-12 |
| [jogacolhue/AlbionBlackMarketMaster](https://github.com/jogacolhue/AlbionBlackMarketMaster) | 3 | TS | 2023-04 |

共同的骨架:

```
数据:AODP /api/v2/stats/prices/{items}?locations=<主城...>,Black Market
利润 = 黑市.buy_price_max × (1 − 税) − 主城.sell_price_min
过滤:两边数据龄超过阈值的丢掉
排序:按利润
```

买侧吃卖单不收费;卖给黑市是吃 NPC 买单,只收销售税,**不收 2.5% 创建费**。

**它们的税率都过时了**:mattias-wiberg 用 3%/6%,felipelincoln 写死 6%。
现行是高级会员 4% / 非会员 8%。差 1 个百分点,对薄利的单子就是盈亏的区别。

### 值得拿来的两个机制

**一、高品质能卖进低品质的买单。** (mattias-wiberg `main.js:284`)

黑市挂"普通品质收 10 万",你拿杰作品质的去一样能成交。所以每个物品要解一个
**分配问题**:主城各品质的货,分别卖进黑市哪个品质的买单,总利润最大。

它的解法是暴力枚举 6⁵ = 7,776 种组合,约束是**每个黑市品质的买单只能用一次**
——因为 AODP 只给最高价不给深度,它只能假设每档就一单。

**我们能做得更好**:抓包拿得到 `AuctionDTO.Amount`,知道每单要几件,
这就变成带容量的分配,不用瞎猜"每档一单"。

**二、20 页上限的绕法。** (mattias-wiberg README 第 4–6 步)

市场列表每页 50 条挂单,全局按价格排,最多 20 页 = 1,000 条。它的做法:
**正序翻 20 页,再点价格列倒序翻,直到碰上正序第 20 页的价格**。从两头往中间夹。

这条顺带证实了 `client-data.md` 第二节留的待办:每页 50 条是挂单(不是物品)、
全局按价排序、上限 20 页(客户端 `MaxPage=19`,0 起算)。

## 商业工具的产品思路(不开源,但公开教程写得清楚)

[Albion Free Market](https://www.albionfreemarket.com/articles/view/albion-online-black-market-flipper-tutorial)
是做得最完整的。几个值得学的:

| 机制 | 它怎么做 | 对我们 |
|---|---|---|
| **两侧数据龄分开** | 黑市买单最多 45 分钟,主城卖单最多 180 分钟 | 黑市买单被其他倒爷吃得快,**必须比主城卖单严** |
| **"已消耗"标记** | 有人做了这单,相关挂单标成已消耗,所有人都看得到 | 单人用不上"给别人看",但"我自己做过这单,别再推给我"有用 |
| **去重** | 同一个黑市买单被多条路线引用时,只留利润最高的 | 就是上面那个分配问题 |
| **附魔升级倒卖** | 买 .0 的,用符文/灵魂/遗物升到 .1/.2/.3,卖进黑市高附魔买单 | 升级材料表在客户端数据里,能做 |
| **私有数据模式** | 只用自己抓的数据,不进 AODP,防 troll 假单 | **我们天然就是**——自己的抓包 |

它给用户的警告也值得照搬:

- 别把银币全压上,倒卖会失败、出货会慢
- **高附魔货在黑市可能卖得很慢,有时要几周**
- 你跑到的时候黑市买单可能已经没了(被别的倒爷吃了,或者价变了),**低阶货更容易这样**

[albionmarket.gg](https://albionmarket.gg/guides/black-market-flipping) 补了一条:
黑市是 Caerleon 的 NPC,收**成品装备和消耗品**,用来给怪物和宝箱掉落供货;
它的收购价**随游戏内需求波动**,一小时前的好价格现在可能就没了。

## 我们的结构性优势

2026-10-19 起只有一个人用(离开了公会),所以"人多刷得勤""全公会协调"这两条
之前写的优势作废。剩下真正站得住的:

1. **有深度。** AODP prices 端点只给最优价,orderbook 端点在 east **实测没部署**
   (`4dcc4a8`)。开源工具根本不知道黑市那单是收 1 件还是 100 件。**我们抓包有 `Amount`**
2. **没有 troll 假单。** 公共 AODP 能被投毒。**自己抓的数据是干净的**

而**数据新鲜度变成了最大的短板**:一个人只能在自己逛过的地方有新数据。
所以"该去刷哪里"这件事要由工具告诉他——见下面第二期的刷新清单。

再加一条它们都没建模的:**进出 Caerleon 的快速旅行边全是 `noluggage=true`**
(`client-data.md` 第二点九节),带货必须骑过去,红区路上会被劫。

## 页面设计

用户对精炼页的反馈是"像在看论文"。黑市页要能**一眼看出下一步去哪买什么**。

一张排好序的采购单,一行一单:

```
物品       品质       去哪买    买价    黑市收   每件赚  能做几件  这单总赚   利润率  数据龄
T6.1 战斧  杰作→普通  Martlock  82,000  118,000  31,280     3       93,840    38%   12 分钟
```

"杰作→普通"表示主城买杰作、卖进黑市普通品质的买单。
"能做几件" = min(主城那档卖单的件数, 黑市那档买单要的件数),两边都来自抓包深度。

**按"这单总赚"排,不按利润率排。** CLAUDE.md 的核心要求是排序主键用绝对收益,
而且用户偏好是"销量 > 利润率"。38% 利润率只能做 1 件,不如 15% 能做 50 件。
利润率作为一列给出,用户想按它排可以点表头。

AODP 兜底的那些行没有深度,"能做几件"显示"未知",排在有深度的行后面——
不知道量的机会不能和知道量的机会放在一起比。

### 必须做对的

1. **品质降级成交** —— 每物品解一次带容量的分配
2. **黑市侧数据龄比主城侧严** —— 先按 AFM 的数:黑市 45 分钟、主城 180 分钟,
   实际跑一段再按命中率调
3. **每个黑市买单只算一次** —— 被多条路线抢的只留最好的那条
4. **税按 4%**(高级会员),配置项可改

### 第二期

- **刷新清单**:哪些品类的黑市数据老了、按价值排,告诉自己下次到 Caerleon 先刷哪几类
  (用双向排序法,一个品类正倒各翻一遍)。单人用户这条比什么都重要
- **"做过了"标记**:点一下表示这单我做了,下次抓到黑市那档买单没了就确认消耗、
  还在就恢复——防止自己反复追一个已经被吃掉的单
- **附魔升级倒卖**:需要升级材料价格和数量

## 第一期做完了(2026-10-19)

「黑市」页签,在「机会」后面。接口 `GET /api/blackmarket?bm_age=45&city_age=180&cities=…`,
代码在 `guild/internal/bm`(分配)和 `guild/internal/flip/blackmarket.go`(取数)。

上面"必须做对的"四条都做了:

1. **品质降级成交**:每个物品解一次最大收益流(主城每档卖单 → 黑市每档买单,货的品质不低于单的品质才连边)。
   不用贪心:"先满足最贵的单"会让便宜的高品质货被低品质的单先拿走,测试里有这个反例。
   另有 400 组随机小例子和逐件穷举对过总利润
2. **两侧数据龄分开**:默认黑市 45 分钟、主城 3 小时,页面上直接改,记在本机
3. **每个黑市买单只算一次**:流的容量就是每档要的件数,几座城抢同一张单时自动分给最赚的
4. **税按配置**(`economics.market_tax`,默认 4%)。卖进黑市只扣税,不收创建费

数据从哪来:每个盘口边用抓包还是 AODP,和扫描同一个择边函数。抓包带件数;
**AODP 只有最优价,件数按 1 件算**,页面上写成"1+"。装备的卖单多半一单一件,按 1 件算
不会把一行的总赚吹大,也就不用把这些行单独排到后面。

抓到的黑市物品多半不在扫描清单里,快照里没有它们的主城价,所以打开页面时现取一次
AODP(同一物品 3 分钟内不重复问,最多等 8 秒),取回来的价查价页和机会页也用。

页面上:顶上一排是整张单做完能赚多少、要带多少本金、黑市有买单的物品数、**上次翻黑市是多久前**;
下面一行一单,在 Caerleon 本地市场买的标"同城"(不用运)。默认按这单总赚排,
点"每件赚""利润率"表头换排序。开着这页每分钟自己刷新一次。

### 还没做

## 风险(不建模成数字,摆给玩家自己判断)

- 黑市买单是**竞争最激烈**的单子,跑到时可能没了
- 运输必须骑进 Caerleon,周边红区全掉落
- 高附魔货出得慢
