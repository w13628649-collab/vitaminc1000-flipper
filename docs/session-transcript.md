## 1. Albion 有没有市场 API

**问:** Albion 有 API 吗?我想要市场物品的价格和销量。

官方**没有**市场 API。官方开放的只有 `gameinfo.albiononline.com`
(玩家、公会、击杀记录)和 `render.albiononline.com`(物品图标)。

市场数据要用社区项目 **Albion Online Data Project (AODP)**,
`https://www.albion-online-data.com/`。SBI 官方默许,因为数据不是从服务器抓的,
而是玩家自愿上传的。

### 基础地址

- 亚服:`https://east.albion-online-data.com`
- 美服:`https://west.albion-online-data.com`
- 欧服:`https://europe.albion-online-data.com`

### 两个核心接口

当前挂单价格(**没有销量**,只有买卖单价):

```
/api/v2/stats/prices/T4_BAG,T5_BAG.json?locations=Caerleon,Bridgewatch&qualities=1,2
```

返回 `sell_price_min` / `buy_price_max` 等字段,每个价格带 `_date` 时间戳。

历史数据(**这里才有销量**):

```
/api/v2/stats/history/T4_BAG.json?date=2026-09-01&end_date=2026-09-19&locations=Caerleon&time-scale=24
```

`time-scale`:`1` 小时 / `6` 六小时 / `24` 按天。
`item_count` 是成交数量,`avg_price` 是均价。**只统计卖单**,买单成交量拿不到。

金币价格:`/api/v2/stats/gold.json?count=2`

### 四个坑

1. **数据是众包的,会过期**。必须检查 `_date` 判断新鲜度
2. **物品 ID** 在 ao-bin-dumps 的 `formatted/items.txt`,城市 ID 在 `world.txt`。
   格式 `T4_BAG`、`T6_2H_AXE@2`(`@` 后是附魔等级)
3. **质量** `qualities`:1 普通、2 优秀、3 杰出、4 卓越、5 大师
4. 限流 180 次/分钟、300 次/5 分钟;URL 上限 4096 字符。
   **一次请求塞几十个物品 ID 比循环单请求划算得多**

## 2. 国外工具的实时数据怎么来的

**问:** 欧美服有软件能看实时价格、销量和制造利润率最高的物品,怎么做到的?
听说官网有收费 API。

### 官方收费 API 不存在

SBI 从来没开放过市场数据 API,论坛上有开发者正式申请过,官方没给。
听到的"收费 API"基本都是第三方把免费的 AODP 数据包一层壳按月转卖。

### 三层架构

**第一层:客户端抓包。** `albiondata-client`(Go,MIT 开源)监听本机网络流量,
识别 Albion 相关 UDP 包,发到中心 NATS 服务器。
Windows 依赖 Npcap,Linux 用 libpcap。

**第二层:NATS 消息总线(实时的关键)。** 国外站点**不是轮询 REST API**,
而是订阅 topic:

```
亚服:  nats://public:thenewalbiondata@nats.albion-online-data.com:24222
美服:  nats://public:thenewalbiondata@nats.albion-online-data.com:4222
欧服:  nats://public:thenewalbiondata@nats.albion-online-data.com:34222
```

Topic:`marketorders.deduped`、`markethistories.deduped`、`goldprices.deduped`。
带 `.ingest` 后缀的是未去重原始流。

- **5 分钟窗口去重**
- **订单没有"成交"事件**。官方建议:记录订单最后出现时间,
  超过 X 小时未再出现视为已成交
- 历史时间戳是 C# ticks:`(ticks - 621355968000000000) / 10000000`

**第三层:网站自己算。** NATS 流灌进自己的库,叠配方数据算利润。

### 三个坑

1. **"实时"本质还是众包**。必须有人在游戏里翻到那一页市场,价格才会上传
   (上传后立刻可见)。**亚服人少覆盖率明显差**
2. **市场订单加密**。新号的挂单被加密传不了,金价和历史价不受影响。
   养号是目前唯一已知的规避方式
3. **有私有上传模式**,`-p` 参数

## 3. AODP 的数据库 dump

**问:** 官方只有每日数据库吗?里面包含什么?

⚠️ **纠正:那个每日数据库不是官方的**,是 AODP 社区项目自己的库备份。

### 实际内容(`/database-east/`)

| 文件 | 内容 | 大小 |
|---|---|---|
| `db_backup_YYYY-MM-DDTHH_MM_SS.tgz` | 每日全库 | ~250 MB |
| `monthly_db_backup_YYYY-MM.tgz` | 每月归档 | ~250 MB |
| `market_history_YYYY_MM.sql.gz` | 单月成交历史 | 40–60 MB |

官方 README:每日备份含全部当前价格 + 6 个月加当月的市场历史。
想要全部历史,**先导入最新每日备份,再按倒序逐月导入**。

### 坑

- **每日备份只留约 4 天**,要长期存档得自己定时抓
- 月度历史文件**滞后约半年**
- **导入 ID 冲突**:2023-12 前后导入 2023-03 数据可能冲突,
  先删 2023-03 区间再导入
- 是 MySQL dump 格式,用 ClickHouse 需要转换层

用途是**冷启动**:立刻拿到全量当前价 + 半年成交历史。

## 4. 自己抓包存自己的库

**问:** 我能不能用 albiondata-client 抓包,手动进游戏查价,存到自己的库?

可以,客户端原生支持。

### 配置

```bash
albiondata-client -i noop -p http://127.0.0.1:9000
```

`client/config.go` 里的参数:
- `-i` — PUBLIC 数据目标,默认 `http+pow://albion-online-data.com`,
  可以是 `nats://`、`http://` 或 `noop`,多个逗号分隔
- `-p` — PRIVATE 数据目标,取值规则同上
- `-d` 禁用所有远程上传
- `-l` 指定监听网卡
- `-o` 解析本地抓包文件(自动开启 offline 并禁用上传)

### 接收端

HTTP uploader:`POST {baseURL}/{topic}`,`Content-Type: application/json`,
返回 200 即成功。topic 是 `marketorders.ingest` 等。

```python
from fastapi import FastAPI, Request
import json, aiofiles

app = FastAPI()

@app.post("/{topic}")
async def ingest(topic: str, req: Request):
    payload = await req.json()
    async with aiofiles.open(f"{topic}.jsonl", "a") as f:
        await f.write(json.dumps({"topic": topic, "data": payload}) + "\n")
    return {"ok": True}
```

客户端还支持 websocket 输出,同目录放 `config.yaml` 设 `EnableWebsockets: true`。

### 四个现实约束

1. **市场是本地的(最大问题)**。只能看当前所在城市的挂单
2. **手动翻页吞吐量远远不够**。技巧:按大类筛选翻列表页;
   **装备预设的快速购买界面一次加载很多物品价格**,是已知的批量扫描入口
3. **千万别上鼠标宏**。抓包被允许是因为只看不改。
   论坛有人用鼠标宏嗑洞察之书被举报封号
4. **加密**。新号挂单传不了

## 5. 游戏协议为什么能抓包解析

**问:** 游戏协议肯定是 wss 或 https,这个 SDK 怎么能解析出来?

⚠️ **前提错了——游戏主逻辑根本不走 HTTPS/WSS。**

用的是 **Photon**(Exit Games 商业网络中间件),跑在 **UDP 5055 / 5056**,
自己在 UDP 上实现可靠传输和分片。HTTPS/WSS 只用于登录鉴权、
`gameinfo` web API、补丁 CDN。

不是 SDK 厉害,是**那部分流量压根没加密**。
Wireshark 敲 `udp.port == 5056` 就能看到。

### 四层解析(`client/listener.go`)

1. **pcap 抓包**:`SetBPFFilter("tcp port N || udp port N")`,
   TCP 也带上是因为 Photon 会回退到 TCP
2. **Photon 传输层**:拆包头、拆命令、`photon.FragmentBuffer` 重组分片。
   单个 UDP 数据报可能背靠背装多个 Photon 包,靠 peerId/challenge 扫边界
3. **Photon 序列化层**:`Protocol18Deserializer` → `map[byte]interface{}`。
   回调:`OnRequest` / `OnResponse` / `OnEvent` / **`OnEncrypted`**
4. **Albion 业务层**:认 operation code。
   **市场订单在参数里本身就是 JSON 字符串**,不需要深度解析二进制

### 两个关联结论

- **加密是选择性的**,按账号下发。`OnEncrypted` 回调就是"新号传不了挂单"的底层原因
- **客户端要跟版本更新**:operation code 数值在游戏更新时会变

如果真是 TLS,只能 MITM,那就从"只看"变成"干扰",踩 SBI 红线。

各语言解析库:Go `photon_spectator`、C# `Protocol18Deserializer`、
Rust `photon_decode`、Python AlbiPy。

## 6. 精炼 vs 装备制造

**问:** 半成品和装备,哪个销量大利润高?有没有攻略?

不是"哪个更赚",是两种生意模式:

| | 精炼半成品 | 装备制造 |
|---|---|---|
| 销量 | 极大 | 小,款式冷热差大 |
| 利润率 | 薄 | 厚但波动大 |
| 逻辑 | 靠**周转率** | 靠**信息差 + 专精** |
| 风险 | 几乎不压货 | 压货、品质随机 |

**排序主键是"日化收益率"(利润 × 周转次数),不是单笔利润率。**

### 利润杠杆(按重要性)

1. **资源回收率**——最大杠杆,加成城 + 专注可达 53.9%
2. **专注 + 高级会员**——硬门槛,没专注利润率小很多
3. **工作站费率**——15–25% 的站费会吃掉全部利润
4. **别在个人岛制造**——⚠️ 真正原因是**岛上完全没有城市生产加成**,
   不开专注回收率为 0
5. **税费**——premium 4%,非会员 8%,加 2.5% 挂单费
6. **日志 + 工人**
7. **专精**——不直接提高回收率,而是降低专注消耗

### 运输

精炼后的材料比原材料**更重**。精炼材料在**精炼城市当地往往卖得更好**。

### 关于攻略

攻略给的是方法论不是答案。公开的"最赚钱清单"在被写出来时就开始失效,
而且大部分是欧美服玩家写的,亚服供需完全不同。

## 7. 多账号方案

**问:** 每个号焦点有限,石头不赚钱,打算起 4 个号各做一种半成品。

⚠️ **纠正:焦点和 premium 都是按角色算的,不是按账号。**

有 premium 的角色初始 30000 焦点,每天恢复 10000,上限 30000,
**满上限后停止恢复**。一个账号最多 3 角色,但**同账号一次只能登录一个角色**,
所以多城并行必须多账号。成本上没差别,premium 按角色收费。

### 没算到的 16 倍杠杆

精炼焦点消耗**每累积 10000 点焦点成本效率减半**;
T4–T8 全点满累计 40000 点,降到基础值的 **6.25%**。

| 方案 | 每日焦点 | 效率 | 等效产出 |
|---|---|---|---|
| 4 个零专精角色 | 40000 | 100% | 40000 |
| 1 个满专精角色 | 10000 | 6.25% | **160000** |

结论:铺开不是错,但**顺序很重要**——别 4 条线同时慢慢爬。

### 真正的约束可能是资本,不是焦点

4 角色每天烧 10000 焦点精炼 T6–T7,需要的白银流水不小。

### 关于"石头不赚钱"

作为起步排除合理,但这是"听说"不是数据。
石头需求会在公会建据点时脉冲式上涨。**多记一个物品成本是零,一起记上。**

## 8. 多开是否可行

**问:** 听说一台机器只能登录一个号一个角色。

⚠️ **说法不对。一台机器可以同时跑多个客户端,官方明确允许。**

误传来源是把"**同一个账号**一次只能登录一个角色"(真的)
误传成"一台机器只能登一个号"。

### ToS 11.2

允许多重注册和运营多个账号。但**同时**使用多个角色时:

1. 角色之间不得互动或协作,**除非位于城市、据点、个人岛或公会岛内**
2. 不得一起参与战斗
3. 不得互相充当斥候
4. **这些角色必须都开通高级会员**

另有明确禁止:多账号同时在游戏世界里一起采集。

⚠️ **Claude 自己推翻的建议:**之前说"挂免费小号当扫描器,零成本"——
如果和别的角色**同时在线**,违反第 4 条。要么错开时间,要么都买 premium。
条款措辞有模糊地带,**待办:发邮件问 SBI support**。

### 技术实现

- 官网版、Steam 版、Epic 版可共存,限制在角色层面
- **手机/平板**:AFM 有 Android 数据客户端,一台平板就是一个独立扫描节点
- 虚拟机要用**桥接模式**
- 4 开把画质最低,每实例内存 2–4 GB

### 抓包的意外好处(待验证)

4 客户端同机 = 同一张网卡 = **一个 albiondata-client 能抓全部**。

**但上游仓库 TODO 明确列过"处理多个同时运行的客户端??"**。
多客户端并行时能否正确区分城市归属,是已知悬而未决的问题。
**先用 2 个客户端(不同城市)做对照测试。**

## 9. Thetford 的城市加成到底是 18 还是 40

**问:** 我在 Thetford 炼钢条,面板上写 18% 又写 40%,到底是哪个?

**两个都算,相加。总加成 58%。**

- **+18%** 是每座皇家城市、凯尔利恩、Brecilien 都给的**基础生产加成**
- **+40%** 是 Thetford 对**矿石**的专属加成,叠在基础之上

### 换算

| 情况 | 加成合计 | 回收率 | 实际材料成本 |
|---|---|---|---|
| 加成城 无专注 | 58% | 36.7% | 63.3% |
| 加成城 + 专注 | 117% | **53.9%** | 46.1% |
| 非加成城 + 专注 | 77% | 43.5% | 56.5% |
| 非加成城 无专注 | 18% | 15.2% | 84.8% |

15.2% 就是 0.18 / 1.18。**专注值 17.2 个百分点的材料成本。**

### 三个注意点

1. 面板上的"**制造加成 +18%**"是装备制造用的,跟精炼无关。
   制造的城市专属只有 **+15%**,远小于精炼的 +40%
2. **法师魔塔做魔法武器,炼钢条要找熔炉**
3. **必须比价**。费率玩家自定,上限每 100 营养 1000 银
   (Foundations 更新后从 10000 降下)。按 **N 键**看地图,
   **点击建筑高亮所有同类型**,悬停逐个看费率。
   还要看**食物和耐久**——没营养或没耐久就不能制造

钢条是 T4,配方是铁矿 + 低一阶的青铜条。
**回收率对全部投入生效**,包括那根低阶锭。具体数量从 `items.json` 确认。

## 10. 第三方工具怎么选

**问:** AODP 上推荐的工具大部分收费,不知道有没有用、真不真实。

⚠️ **Claude 自己纠正:**之前说"这些工具一旦收费就构成违规",**说得太绝对**。

SBI 2020 年关于第三方软件的公告给的实际标准:

- 在 PvE、采集或 PvP 上给直接好处 → 禁止
- 修改客户端,或在客户端内额外显示信息(overlay / radar) → 禁止
- 数据聚合通常可接受,条件含"数据在网站上提供而非游戏内覆盖层"、
  "不提供实时的游戏内优势"
- **公开条款里没有提到收费与否**
- 拿不准发邮件问官方

### 关键:那个工具列表是自助提交的

AODP 的 3rd Party Tools 页面底部写着:想列在这里就去 GitHub 提 PR。
**上榜门槛只是有人提了 PR,没有审核、没有背书。**
页面顶部还挂着免责声明:这些工具与 Albion Online 或 SBI 无关联。

真正的信号只有两个:**是否开源**、**是否明确标注免费**。
19 个工具里描述明确写 free 的只有四个:Royal Forge、ALLbeON、AlbionKit、
AlbionSnipe。其中 **AlbionKit 是唯一写明开源的**。

### 对口倒爷的工具

| 工具 | 能力 |
|---|---|
| **AlbionSnipe** | 免费。读**本地** albiondata-client 数据流,把你浏览的挂单跟黑市和每个皇家城市比价,对比该物品 7 日/30 日均价。additive 模式,照常上传 |
| **Albion Profit Forge** | **反向搜索**:算出所有城市和黑市间的每条路线,列出现在值得做什么,按利润排序,**带 troll 过滤**,按命运面板个性化 |
| **Albion Online Hub** | 实时倒卖(含运输路线和附魔差价)、订单追踪。**明确支持所有区域服务器** |
| **AlbionKit** | 免费开源。市场倒卖器 + 运输路线利润计算 |

**AlbionSnipe 的价值在于它读本地数据**,直接绕开亚服覆盖率问题——
你看到的价格就是当下真实的。

### 付费工具的真正问题

不是贵,是**数据源跟免费的一模一样**,全是 AODP。
收费买的是 UI、缓存、告警,解决不了亚服数据新鲜度这个真瓶颈。

### 有一类工具真会封号

radar、auto-scout、游戏内 overlay 是官方点名禁止的。**别碰。**

## 11. 倒爷策略

**问:** 我有 1000 万银币,想先当倒爷,低价买高价卖。销量优先,其次利润。
要现金流健康、回本快。

**用户已确认持有亚服 premium** → 市场税 4%。

### 三个数字

**1. 摩擦成本 6.5%**

卖出交市场税(premium 4%),挂单另收 2.5% 手续费。
即时买入 + 挂单卖出的往返摩擦 ≈ **6.5%**。
(非会员是 10.5%,所以 premium 对倒爷是**直接的税率问题**,不是焦点问题。)

价差必须**显著高于 6.5%** 才有意义。

**2. "销量优先"是对的,但指标要改**

别看 `item_count` 绝对值,看 **item_count × 价格 = 日白银流水**,
再跟 1000 万本金比。

例:某物品日成交 500 个、单价 2000 → 日流水 100 万银。
1000 万本金一次吃 200 万 = 占掉两天的全部成交量 → **根本出不掉货**。

**倒爷的真正约束是"能吃下市场多大比例而不砸价"**,不是价差有多大。

**3. 先做同城价差,而不是跨城运输**

| | 同城买卖单价差 | 跨城运输 |
|---|---|---|
| 单笔利润 | 小 | 大 |
| 周转时间 | 几分钟 | 几十分钟 |
| 风险 | 无 | 路上有风险,压着货 |
| 本金占用 | 低 | 高(钱锁在路上) |

**跨城运输最大的隐性成本是"钱被锁在路上"**,跟"现金流健康"直接冲突。

### Troll 数据 — 自己写时最容易漏的一环

市场上有大量恶意挂单:1 件货、价格是正常值几十倍的卖单,或极低的买单,
专门污染数据。**任何天真的价差计算器都会把这些显示成天大的机会。**

根本原因:**AODP 的 prices 端点不返回挂单数量**,只有价格。
"最低卖价 1000"可能只对应 1 件货。

这也是本地抓包优于纯 API 的地方。过滤方案见 `SPEC-flipper.md`。

### 工程量澄清

用户担心"自己写要做的东西挺多"——**把两件事混在一起了**。

前面设计的 NATS + ClickHouse + 制造利润模型是为**精炼/制造**准备的,
工程量确实大。但**倒爷工具小得多**:批量拉价 → 算税后价差 →
按新鲜度过滤 → join 成交量 → 排序。约 80 行 Python,不需要 NATS 和时序数据库。
